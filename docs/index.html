  3. They draw the other half, then unfold the page.

Send

The short link uses Chinese characters to pack more into each one. Use it in chats that count characters, such as Discord or Telegram. When copied from a browser's address bar it becomes much longer, so send it from here.

Other ways to send

A code works without the link: paste it on the Exquisite Corpse home page. The file is a PNG that shows only the visible strip, with the drawing stored inside. Send it as a file or email attachment: messengers that compress photos remove the drawing.
